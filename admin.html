How to get an access token (one time)
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token and give it a name.
  3. Under Repository access, choose Only select repositories and pick Islamic-stories.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate the token, copy it, and paste it below.

The token works like a password for this one repository. Do not share it. This page sends it only to GitHub.
